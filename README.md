# 酒馆输入框修复助手 (st-input-fix)

SillyTavern 扩展：解决手机端输入框跳来跳去、不好打字的问题。

## 做了什么

- 把输入框固定高度（默认 44px），禁止自动增高和手动拉伸，文字超长时输入框内部滚动
- 软键盘弹起时把输入栏钉在键盘上沿，键盘收起自动还原，不再上下跳动
- 聚焦、键盘弹出/收起全程稳定
- **不触碰**角色卡、世界书、聊天存档、API 配置，随时可停用/卸载

## 安装

酒馆 → 扩展(Extensions) → 安装扩展 → 粘贴本仓库地址 → 安装 → 刷新页面

## 设置面板

安装后，酒馆「扩展」面板里会出现「酒馆输入框修复助手」设置块（点击标题可折叠/展开，状态自动记住，标题旁显示版本号与生效状态）：

- **启用修复**：总开关（标题旁 ● 绿点 = 启用中）
- **输入框高度**：默认 44px，可调 24~120px，支持 −/+ 微调按钮，修改即时生效
- **键盘弹起时钉住输入栏**：开启后输入栏贴键盘上沿
- **自动检测并调节**：默认开启。自动检测键盘钉住是否被顶掉、输入框高度是否被改走并自动修复；键盘弹起期间轮询加速，收起后自动回到省电频率
- **发送后自动聚焦输入框**：可选，开启后发送消息自动把焦点还给输入框，连续聊天不用再点（默认关闭）
- **立即自检**：点一下立刻检查扩展/高度/键盘状态，结果显示在面板日志行
- **恢复默认**：一键还原

设置保存在浏览器本地，不触碰任何数据。

## 建议同时关闭（可选，效果更佳）

设置 → 界面设置：

- 流式渐显 (Stream Fade-In) —— 关闭不影响自动滚动聊天

## 卸载

扩展面板里停用/卸载即可；所有修改均为样式级，无副作用。
