# 酒馆输入框修复助手 (st-input-fix)

SillyTavern 扩展：解决手机端输入框跳来跳去、不好打字的问题。

## 做了什么

- 把输入框固定为 44px 高度，禁止自动增高和手动拉伸，文字超长时输入框内部滚动
- 聚焦、软键盘弹出/收起时，整条输入栏不再上下跳动
- **不触碰**角色卡、世界书、聊天存档、API 配置，随时可停用/卸载

## 安装

酒馆 → 扩展(Extensions) → 安装扩展 → 粘贴本仓库地址 → 安装 → 刷新页面

## 建议同时关闭（可选，效果更佳）

设置 → 界面设置：

- 自动滚动聊天 (Auto-scroll Chat)
- 流式渐显 (Stream Fade-In)
- 扩展输入区

## 卸载

扩展面板里停用/卸载即可；所有修改均为样式级，无副作用。
